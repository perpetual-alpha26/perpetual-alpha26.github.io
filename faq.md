<div class="page-header" style="text-align: center; margin: 4rem 0 2rem 0;">
    <h1 style="font-size: 2.5rem; margin-bottom: 2rem; color: var(--accent-color);">Frequently Asked Questions</h1>
</div>

<div class="faq-container" style="max-width: 800px; margin: 0 auto; padding-bottom: 4rem;">
    
    <details class="faq-item">
        <summary>Can we use external data sources during the competition?</summary>
        <div class="faq-answer">
            Yes, you will be allowed to use external data sources during both the practice and scored trading phases.
        </div>
    </details>

    <details class="faq-item">
        <summary>How much do we need to disclose about external data in our report or code submission?</summary>
        <div class="faq-answer">
            At the end of the competition, you will be asked to submit both your code, which will be accessible only to a jury of experts, and a PDF report describing your model and strategy. Both submissions will be part of the evaluation. We therefore strongly encourage teams to document any external data used, including the relevant data sources and, where appropriate, how the data were processed and incorporated into the model. Transparency on this aspect will help the jury properly assess the methodology.
        </div>
    </details>

    <details class="faq-item">
        <summary>Will the organizers provide market data (and on-chain data) for backtesting? What will it include, and when will it be released?</summary>
        <div class="faq-answer">
            Yes, we plan to provide historical time-series data that you can use for model development and training. We are still finalizing the exact dataset and format. At this stage, we expect the provided historical data to consist primarily of price time series. More detailed information on the dataset and its release will be communicated once the final setup has been confirmed.
        </div>
    </details>

    <details class="faq-item">
        <summary>Is the submitted code just for the jury's review, or does it need to be reproducible? Will there be requirements on the execution environment, dependencies, or documentation?</summary>
        <div class="faq-answer">
            The submitted code will be reviewed by the expert jury as part of the final evaluation and will be used to assess the implementation of the proposed strategy and its consistency with the accompanying report. We are still finalizing the exact requirements regarding reproducibility, execution environment, dependencies, and documentation. Further details will be communicated to participants soon.
        </div>
    </details>

</div>
